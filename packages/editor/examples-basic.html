Basic Usage

The shipped <km-editor> element — each input as ONE live editor you drive with control switches: view mode & read-only, the I/O format lens, toolbar & status-bar placement, theme, and a declarative no-JavaScript setup.

EB01 · View Mode & Editing

One document, four presentations. mode switches between edit, split (editor + live output), preview (read-only render), and inline. readonly blocks input; preview forces it on. The mount is persistent, so the document and selection survive a mode switch.

EB02 · I/O Format Lens

format is only the serialization lens for content I/O — switching it re-reports the SAME document as markdown, html, or json; it never rebuilds the document. The readout below is the live change event's detail.value in the chosen format.
