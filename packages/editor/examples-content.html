Rich Content

The first-party content plugins on a small live <km-editor> — links, images, tables, and code with syntax highlighting. Each card shows the feature landing in the document, with its live serialization beside it so you can see exactly what the editor produced.

Output lens — read the same document in any format:

format is just a lens on one ProseMirror document. HTML and JSON round-trip losslessly; Markdown is lossy at the edges — flip to HTML on the table card to see the same table go from a raw-HTML blob to a clean <table>.

RC01 · Links

The link plugin adds a link mark, the insert-link command (bound to Mod-K), and the 🔗 toolbar button. Select some text, then apply a link — the Markdown [text](url) appears on the right.

or select text and press Mod-K / click 🔗

RC03 · Tables

            

                The tables plugin adds an editable table (⊞ toolbar button) with
                row/column commands. One thing worth seeing: a table exports as a raw-HTML GFM
                fallback and does not parse back into nodes on Markdown import — watch the
                live output switch to an HTML <table> block.
