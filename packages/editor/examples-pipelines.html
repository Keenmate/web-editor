Pipeline Lab

The content-pipeline layer under a microscope. These are the “plain pipeline” demos — the mechanism itself, without a feature wrapped around it: a live run visualizer, the design-stage phase/config-cell assembly model, and the image use cases running end to end on real Blobs.

Run Visualizer

An editor beside one lane per pipeline — each stage chip blinks green → gray → amber → red by state.

Editor ⏳ locked — pipeline running

Type here — the derive pipelines run off the change event (debounced). A gating async paste locks the editor until it finishes.

Pipelines

One lane per pipeline. Stages: green=running → fades gray=ok, amber=halt, red=error, dashed=skip, struck=aborted.

• Sync paste (transformPastedHTML): cleans and inserts immediately — can't await. Try Simulate paste (sync), or real Ctrl+V with paste mode = sync.
• Async paste (handlePaste): cancels the native paste, awaits fetch-meta (watch the delay slider), pauses on the confirm-import modal, then inserts via a transaction. Try Simulate paste (async), or set paste mode = async then Ctrl+V. Cancel the modal → nothing is inserted.
• Cloud image (image:browser:pick, a command-triggered deferred pipeline): the toolbar ☁ button or Insert cloud image opens a picker (modal), uploads (watch the delay), then inserts — the editor is locked for the whole run. Toggle base64 and watch a to-base64 stage appear before insert (a second plugin splicing into the pipeline).
• Type secret → policy halts (amber); forbidden → errors (red).
• Enable classify, then type → modal pauses the idle lane.
• Type fast during a run → in-flight stage is struck through (aborted / superseded).
• Sync-paste something containing <script> → guard-scripts halts (blocked).

Phases & Config Cell design-stage

A prototype of the phase-based assembly + config-cell model (see PIPELINES.md). Independent plugins declare a phase; the pipeline owns the ordered vocabulary; the app owner disposes via order / assign; config resolves per (stage × pipeline) cell and reaches each stage as rt.config. Not in the shipped engine.

Image Pipeline Use Cases design-stage

The cloud-image use cases from PIPELINES.md, running end to end with real Blobs: (A) an interactive crop editor stage, (B1) a planner driving the same crop stage headless, and the plugin-API wrapper + batch + adapter flow building a gallery. Built on the phases prototype; the shipped engine is untouched.
